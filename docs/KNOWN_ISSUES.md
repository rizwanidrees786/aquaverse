# Known Limitations & Issues

1. **Sandboxed Build Verification (`v0.1.0`):** Automated `flutter pub get`, `dart run build_runner build`, `flutter analyze`, `flutter test`, and Android APK/AAB builds were not executed inside this container because no network package mirror or Android SDK runtime is attached to the sandbox. Run these commands locally or via `.github/workflows/android-build.yml` on GitHub Actions.
2. **Generated Drift Code (`*.g.dart`):** `lib/core/database/app_database.g.dart` is generated by `build_runner` from Drift annotations. Running `dart run build_runner build --delete-conflicting-outputs` generates it automatically once `drift_dev` is fetched.
3. **Domain Modules (Phases 5–32):** Specialized editors and calculators for full livestock species catalogs, water chemistry formulas, equipment turnover, aquascaping, marine/reef, breeding, IoT devices, business CRM, marketplace, and billing are scheduled for ZIP Deliveries 02–08 (`v0.2.0`–`v0.8.0`).
